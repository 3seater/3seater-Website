TOOLS AND SKILLS

Official Framer External Agent
https://www.framer.com/agents/external/
Framer documents an external bridge, installed via npx @framer/agent setup, and a /framer skill. It can work with canvas, components and CMS in explicitly connected Framer projects. A project connection is required. This is the direct route if the user elects to build natively in Framer. Not installed or connected here.

Framer native Skills
https://www.framer.com/skills
These are instructions inside Framer's agent/project context, including reusable design-system guidance. They are not evidence that a Framer skill is already installed in this workspace. For this exploration, one global design-system skill across twenty sites could recreate the sameness problem; keep visual direction local to each concept.

Motion AI Kit
https://motion.dev/docs/ai-kit
Official skill and MCP for coding agents. Free documentation search and best practices; premium tools/example source require Motion+. Motion itself is a free MIT-licensed animation library for React, JavaScript and Vue. This is the most directly relevant addition for building Framer-quality interactions in the existing codebase. Not installed.
https://motion.dev/

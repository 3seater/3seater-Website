# Design System: 3seater — Batch Nine

## Overview

A color-only continuation of favorite batch-seven/03 Soft Capsule, confirmed by hyperlink and screenshots. Scope: /batch-nine/01/ through /batch-nine/10/. The production portfolio is unchanged.

## Colors

The exact authority is `palettes.json`; frontmatter records its current tokens. Only each route's `palette.css` differs. Shared color rules apply palette values without recoloring artwork.

## Typography

Inherit the favorite's complete typography unchanged, including Anton display and Plex supporting roles. No changes to family, scale, weight, tracking or casing.

## Layout

All ten routes have byte-identical HTML, project data and site metadata, with shared JavaScript and structural styles. Preserve the favorite's grid, selected-project list before the client wheel, Archive and project detail layouts.

On home, capsule spacing is equal above and below: 24px desktop and 20px at widths up to 700px. The scoped `favorite.css` header padding implements this spacing.

## Elevation & Depth

Retain Soft Capsule's material, blur and depth treatment. No palette introduces new shadows or geometry.

## Shapes

Preserve the capsule and all existing component geometry across every palette.

## Components

Navigation, archive filtering, media, factual content and runtime behavior inherit batch-seven/03. Footer cursor-pressure distortion is removed; the static wordmark, home link and responsive fitting remain. The favorite itself receives its scoped favorite.js/favorite.css update.

## Do's and Don'ts

- Do preserve factual portfolio data, original-color artwork and inherited media behavior.
- Do keep all ten routes structurally identical and use palettes.json for exact colors.
- Do retain equal home capsule spacing and static footer fitting.
- Don't introduce typography, structure, navigation or content variations between palettes.
- Don't propagate palette tokens to the main site or historical batches.

Batch nine wheel color refinement: inactive cylinder names use a palette-derived 20% ink / 80% paper color, retaining #c8cbd0 for Original Frost (01). Active names and static client lists retain the main ink color. No layout changes.

3seater / Design audit / October 12, 2026

More Sturdy. Keep the archive.

Give the controls a stronger identity, make typography consistent, and let the work carry the page. Preserve the staggered homepage, ordered category grids, compact index, and dark audio cursor.

Reference review: Sturdy home, work archive, project page, and Reuben Timothy. Measurements below come from live DOM/computed styles and delivered CSS. Our comparison uses the local source and supplied screenshots. Desktop reference measurements use a 1440px viewport; responsive rules were also inspected. Some measurements are fluid, not universal constants.

01 / What each reference contributes

Sturdy: a strong contrast between small controls and large work, regular-weight grotesk typography, dark rounded navigation, and a consistent translucent circular interaction treatment. Its image edges remain square. Rounded shapes belong mainly to controls. The result feels deliberate because each shape has a job.

Reuben: dense image browsing, compact labels, centered text navigation, and a useful index. Its homepage uses five image columns with 10px gaps at large widths; its declared utility type is 11px with .06em tracking. Our existing navigation, grid density, project split view, and index structure closely follow that direction.

Recommended balance: retain our efficient browsing structure and use stronger controls, clearer type roles, and more intentional image selection to move toward a studio presentation. The work is already visually rich. Extra slogans, badges, decorative cards, and explanatory copy would dilute it.

03 / Typography audit

Our source named Helvetica Now Display, NB Akademie Std, and PP Supply Mono without supplying their webfont files. On this Windows environment, those stacks can fall through to Arial or Consolas. The intended type system therefore was not reliably the rendered type system.

The first pass makes the sans choice explicit: Arial with Helvetica and sans-serif fallbacks. It is a dependable baseline, not an exact substitute for FK Grotesk. Obtaining and properly loading a chosen webfont remains the clearest next typography improvement. The pass does not copy reference-site font files.

04 / Navigation and controls

The main navigation now sits to the right of the brand in dark pills. The active page has a lighter charcoal fill; hovering uses a separate charcoal state. The pills retain visible keyboard focus. On mobile, navigation moves onto its own row and uses a 44px minimum height.

Category filters remain a quieter, underlined second tier. Making every category another dark pill would give the top of the archive too much visual weight. The primary navigation identifies destinations; filters refine the current destination. They should be easy to distinguish.

The existing orange accent remains available for project links and filters, while the main navigation stays monochrome. A restrained accent can retain our identity without competing with the artwork.

Keep the audio orb: its dark circular surface and white icon already give a clear action over changing video frames. Its tracking, mute behavior, keyboard treatment, and touch fallback are unchanged. If we later extend that visual treatment to project thumbnails, use a directional icon only over linked media, and keep the native cursor elsewhere.

05 / Grid, padding, and image hierarchy

The homepage and archive now deliberately serve different browsing modes. The homepage retains shortest-column masonry for a tightly packed arrangement of mixed aspect ratios. Category pages retain row-major ordering, so a sixth item in a five-column layout starts at the left. This separation stays intact.

The pass uses 10px horizontal image gaps and 24px between project groups, reduced from 30px. Captions stay 8px below their images. Outer padding is a bounded 12–20px. The header uses a 76px minimum height on desktop, and the archive begins 24px below it. These repeated distances give the page a steadier rhythm.

The largest unimplemented opportunity is selection. Our “Selected Works” route currently includes all projects, just as the unfiltered archive does. Prioritizing roughly 10–14 representative projects would make the homepage feel edited and give visitors a reason to use the archive. That is a content decision worth making deliberately, rather than silently hiding work.

A later layout pass could enlarge a small number of chosen homepage projects while preserving the staggered composition. Avoid assigning importance solely from image height or file order. Preserve artwork aspect ratios; any crop for a thumbnail should be explicitly art-directed.

06 / Motion and performance

The category fade remains confined to the work grid. Navigation should respond immediately and stay visually stationary during filtering. Keep the existing short fade durations rather than introducing longer transitions that delay browsing.

Several visible videos can currently play together, and the feed loads full video sources when they enter view. The build also creates short previews. A future optimization should compare those previews against the originals for sharpness and then use them where quality is sufficient. This pass does not change playback quality or introduce hover-only playback.

The client wheel is already the page’s prominent motion feature. Its scroll region grows by 70px per client, in addition to 85vh. That deserves a later pacing review: a large client list can make reaching contact feel slow. Keep it as the single expressive feature before adding any further motion.

Reduced-motion support remains in place. The new navigation color transition also explicitly switches off under that preference.

07 / Structure and maintenance findings

The stylesheet contains multiple historical versions of header, type, grid, and breakpoint rules, including unused hero styles. That makes broad adjustments prone to cross-page effects—the homepage/category regression was an example of why route-specific layout rules matter.

The current pass is intentionally bounded. A subsequent cleanup should consolidate each component’s final rules, remove confirmed dead selectors, and retain separate homepage, archive, index, and project layout scopes. Treat the index as a directory and project pages as media viewers; neither needs generic cards or extra narrative text.

Also keep the distinction between project dates and filter years. A project spanning several years can retain that honest date caption while appearing under each individual year filter.

08 / Delivered and remaining

Applied locally: dark pill navigation, explicit sans stack, regular title weights, clearer caption and year text, a cool-white ground, consistent smaller gaps, restrained contact sizing, and mobile navigation sizing. No new page sections or marketing copy were added. The audio orb and both grid algorithms are unchanged.

  1. Next highest value: curate the homepage project selection and sequence.
  2. Typography: choose and load a real webfont with appropriate usage rights; compare it at caption size before committing.
  3. Image hierarchy: test a few deliberate larger homepage placements without flattening the masonry into rows.
  4. Technical polish: consolidate CSS, review video preview quality, and shorten the client-wheel scroll distance if it delays contact.
